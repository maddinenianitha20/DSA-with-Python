Day 07 – DSA Problems

1. Squares of a Sorted Array

Problem: Given a sorted array, return the squares of each element in sorted order.

Example:

- Input: "[-4, -1, 0, 3, 10]"
- Output: "[0, 1, 9, 16, 100]"

Concepts: Arrays, Sorting, Two Pointers.

2. Merge Sorted Array

Problem: Merge two sorted arrays into one sorted array.

Example:

- Input: "nums1 = [1, 2, 3, 0, 0, 0]", "nums2 = [2, 5, 6]"
- Output: "[1, 2, 2, 3, 5, 6]"

Concepts: Arrays, Two Pointers, In-place Operations.

3. 3Sum

Problem: Find all unique triplets in an array whose sum is equal to zero.

Example:

- Input: "[-1, 0, 1, 2, -1, -4]"
- Output: "[[-1, -1, 2], [-1, 0, 1]]"

Concepts: Sorting, Two Pointers, Duplicate Handling.

4. Sort Colors

Problem: Sort an array containing only 0, 1, and 2 in ascending order.

Example:

- Input: "[2, 0, 2, 1, 1, 0]"
- Output: "[0, 0, 1, 1, 2, 2]"

Concepts: Arrays, Three Pointers, In-place Sorting.

5. Add List Without Duplicates

Problem: Combine list elements while avoiding duplicate values.

Concepts: Python Lists, List Operations, Duplicate Removal.
