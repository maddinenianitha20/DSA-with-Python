💻 Problems Solved

1. Reverse a String

File: "problem1_reverse_string.py"

Description: Reverse a string without using Python's slicing or built-in reverse methods.

Example:

Input:  python
Output: nohtyp

Concepts: String indexing, lists, swapping, and two pointers.

2. Check Whether a String Is a Palindrome

File: "problem2_palindrome.py"

Description: Check whether a string reads the same forward and backward.

Example:

Input:  madam
Output: Palindrome

Concepts: String comparison, loops, conditions, and two pointers.

3. Count Vowels and Consonants

File: "problem3_count_vowels_consonants.py"

Description: Count the vowels and consonants in a string while ignoring spaces, digits, and punctuation.

Example:

Input: Hello World
Vowels: 3
Consonants: 7

Concepts: Loops, conditions, and string methods.

4. Count the Frequency of Each Character

File: "problem4_character_frequency.py"

Description: Count how many times each character occurs in a string, ignoring spaces.

Example:

Input: banana
Output: {'b': 1, 'a': 3, 'n': 2}

Concepts: Dictionaries, loops, and frequency counting.

5. Find the First Non-Repeating Character

File: "problem5_first_non_repeating.py"

Description: Find the first character in a string that appears only once.

Example:

Input: aabbcde
Output: c

Concepts: Dictionaries, frequency counting, and string traversal.
