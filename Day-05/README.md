Day 5 – DSA Practice (Python)

Overview

Completed five Data Structures and Algorithms problems using Python. This practice helped improve problem-solving skills, logical thinking, and understanding of searching techniques.

Problems Covered

1. Largest Sum of Two Numbers

- Find the two largest numbers in a list.
- Calculate their sum.
- Time Complexity: O(n)
- Space Complexity: O(1)

2. Rotate List by One Position

- Rotate the list to the right by one position.
- Move the last element to the first position.
- Time Complexity: O(n)
- Space Complexity: O(1)

3. Find the First Repeating Number

- Find the first number that repeats while traversing the list from left to right.
- Used a Set for efficient lookup.
- Time Complexity: O(n) average
- Space Complexity: O(n)

4. Linear Search

- Search for a target element by checking each element one by one.
- Works with both sorted and unsorted lists.
- Time Complexity: O(n)
- Space Complexity: O(1)

5. Binary Search

- Search for a target element by repeatedly dividing the search range into two halves.
- Requires a sorted list.
- Time Complexity: O(log n)
- Space Complexity: O(1)

Key Learnings

- Finding the largest elements in a list.
- List rotation using loops.
- Identifying repeating elements using sets.
- Understanding Linear Search and Binary Search.
- Comparing searching algorithm efficiencies.
- Improving logical thinking and coding skills.
