Day 6 – Two Pointers Pattern

Overview

The Two Pointers technique uses two indexes to traverse an array or string efficiently. It helps reduce unnecessary comparisons and improve time complexity.

Problems Solved

1. Two Sum (Sorted Array)

- Find two numbers whose sum equals the target.
- Approach: Two Pointers
- Time Complexity: O(n)
- Space Complexity: O(1)

2. Valid Palindrome

- Check whether a string reads the same forward and backward.
- Approach: Two Pointers
- Time Complexity: O(n)
- Space Complexity: O(1)

3. Remove Duplicates from Sorted Array

- Remove duplicate elements from a sorted array.
- Approach: Two Pointers
- Time Complexity: O(n)
- Space Complexity: O(1)

4. Container With Most Water

- Find two lines that can hold the maximum amount of water.
- Approach: Optimized Two Pointers
- Time Complexity: O(n)
- Space Complexity: O(1)

5. Trapping Rain Water

- Calculate the total amount of water trapped between bars.
- Approaches:
  - Brute Force: O(n²) time
  - Prefix & Suffix: O(n) time, O(n) space
  - Two Pointers: O(n) time, O(1) space

Key Learnings

- How to initialize and move two pointers.
- How to work with sorted arrays and strings.
- How to optimize nested-loop solutions.
- How to calculate time and space complexity.
- How to solve water-container problems using Two Pointers.

Conclusion

Completed five problems using the Two Pointers pattern and understood how to select efficient approaches based on time and space complexity.
