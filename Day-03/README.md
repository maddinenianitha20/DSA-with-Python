Day 3 – String Problems in Python

📌 Overview

Day 3 of my 60-Day DSA Challenge focuses on solving string-related problems using Python. These problems help improve logical thinking, problem-solving skills, and understanding of string manipulation.

🎯 Problems Solved

1. Count Words in a String

Problem: Count the total number of words in a given sentence.

Concepts Used: "split()", "len()"

Example:

text = "Python is easy to learn"

Output:

Total words: 5

2. Remove Duplicate Characters

Problem: Remove duplicate characters from a string while preserving their original order.

Concepts Used: Loops, conditions, string manipulation.

Example:

text = "programming"

Output:

After removing duplicates: progamin

3. Check Anagrams

Problem: Check whether two strings contain the same characters with the same frequencies.

Concepts Used: "sorted()", string comparison.

Example:

first = "listen"
second = "silent"

Output:

The strings are anagrams

4. Find the Most Frequent Character

Problem: Find the character that appears most frequently in a string.

Concepts Used: Dictionaries, loops, "max()", "dict.get()".

Example:

text = "success"

Output:

Most frequent character: s
Frequency: 3

5. Find Common Characters

Problem: Find the characters that appear in both strings.

Concepts Used: Loops, conditions, string manipulation.

Example:

first = "hello"
second = "world"

Output:

Common characters: lo

🧠 Key Learnings

- Counting words in a sentence.
- Removing duplicate characters while maintaining order.
- Checking whether two strings are anagrams.
- Using dictionaries to count character frequencies.
- Finding common characters between strings.
- Improving logical thinking through practical coding problems.
