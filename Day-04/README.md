🧩 Problems Solved

1. Find the Second Largest Number

- Find the second-largest distinct number in a list.
- Approach: Single-pass traversal.
- Time Complexity: O(n)
- Auxiliary Space Complexity: O(1)

Example:

Input: [10, 5, 20, 8, 15]
Output: 15

2. Move All Zeros to the End

- Move all zeros to the end while maintaining the order of non-zero elements.
- Approach: Two pointers and swapping.
- Time Complexity: O(n)
- Auxiliary Space Complexity: O(1)

Example:

Input: [0, 1, 0, 3, 12]
Output: [1, 3, 12, 0, 0]

3. Find the Missing Number

- Find the missing number from a sequence of numbers ranging from 1 to n.
- Approach: Sum formula.
- Time Complexity: O(n)
- Auxiliary Space Complexity: O(1)

Example:

Input: [1, 2, 4, 5]
Output: 3
